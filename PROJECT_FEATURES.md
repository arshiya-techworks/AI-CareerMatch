# Project Improvements / Features Table

| Feature | Basic Version | Improved Version |
|---|---|---|
| Input | PDF/DOCX | PDF only for consistent processing |
| Job Description | Manual text box | Removed; automatic role-profile matching |
| Resume Processing | Text extraction | Text extraction + NLP cleaning |
| AI Model | Basic similarity | TF-IDF + cosine similarity |
| Skill Detection | Simple list | Structured skill matching |
| Scoring | Match percentage | Role + skills + quality + experience |
| Ranking | Manual/basic | Automatic ranking of all resumes |
| Candidate Analysis | Score only | Skills, role, quality, experience, suggestions |
| Skill Gap | Basic | Improvement suggestions |
| Database | None | SQLite screening history |
| Output | Plain text | Dashboard + tables + expandable details |
| Export | None | CSV download |
| UI | Basic | Professional Streamlit dashboard |
| Scalability | One resume | Multiple PDF resumes |
